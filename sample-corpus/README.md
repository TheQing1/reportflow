# 示例知识库

**所有数字均为虚构示例数据，仅用于功能验证，不可用于任何实际决策。**

## 目录结构

```
sample-corpus/
├── 01-行业概览/       行业年度回顾、装机规模与结构统计
├── 02-政策与标准/     国家政策与地方补贴、容量补偿
├── 03-市场与数据/     工商业、电网侧/户用/海外、市场机制
├── 04-技术与成本/     技术路线、系统成本、安全与设备
├── 05-竞争格局/       竞争格局、投融资与展望
└── README.md
```

子目录只影响你自己的组织方式：**检索不看目录，只看文本内容**。
文档 id 取文件名（不含扩展名），所以文件名要全局唯一。

## 单篇格式约定

```markdown
# 标题                       ← 第一行一级标题即文档标题

> 分类：xx · 更新：xxxx-xx · 性质：示例语料

## 要点                       ← 3 条以内的一句话结论
- ...

## 正文                       ← 3 段左右，每段都要带具体数字
...

## 关键数据                   ← 表格，便于检索命中与人工核对
| 指标 | 数值 | 口径说明 |
|---|---|---|
```

换自己的资料时照这个模板写即可：`.md` 或 `.txt`，UTF-8，一篇一个文件。
正文里**尽量写具体数字和口径**（同比、占比、单位），研报流水线靠它们做引用溯源。

## 怎么用

```bash
cd backend
python -m app.cli corpus init     # 知识库为空时，把本目录复制过去
python -m app.cli corpus ls       # 看看有哪些文档、多少片段
```

也可以在界面的「知识库」页直接拖动上传。
